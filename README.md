# DailyTwist — موقع أوتوماتيكي كامل مع وكيل ذكاء اصطناعي

## شنو كيدير المشروع

كل نهار مع 6 ديال الصباح (بتوقيت المغرب)، الوكيل كيخدم بوحدو وكيدير هادشي:

1. كيجيب المواضيع اللي الناس كيقلبو عليها اليوم فأمريكا (Google Trends).
2. كيحيد المواضيع الخطيرة (الموت، الجرائم، السياسة، القمار، الصحة...) باش ما يتسدش ليك أدسنس.
3. كيكتب 3 مقالات احترافية بالإنجليزية على المواضيع الرائجة.
4. كيكتب الأبراج اليومية ديال 12 برج.
5. كيكتب كويز يومي فيه 10 أسئلة.
6. كيبني الموقع وكينشرو أوتوماتيكيا.

وفالموقع كاين حتى لغز يومي بحال Wordle، وعدادات لـ 13 عيد ومناسبة (Christmas، Halloween...)، وكلشي كيتحدث بوحدو.
الصفحات القانونية اللي أدسنس كيطلبها (About, Contact, Privacy Policy, Terms) جاهزة، وحتى sitemap و robots.txt و ads.txt.

## خطوات التشغيل (مرة وحدة فالعمر)

### 1. شري دومين
من Namecheap ولا Cloudflare (تقريبا 10 دولار فالعام). مثال: `dailytwist.fun` ولا أي اسم بالإنجليزية.

### 2. دير حساب GitHub وحط فيه المشروع
- سجل فـ github.com (مجاني).
- اضغط **New repository**، سميه بحال `dailytwist`، خليه **Public**، واضغط Create.
- اضغط **uploading an existing file** وجر **كاع** الملفات والدوسيات ديال المشروع (من بعد ما تفك الـ zip).
- ⚠️ الدوسي `.github` مخبي فبعض الحواسب. إلا ما بانش ليك: فـ Windows دير View > Hidden items، وفـ Mac اضغط Cmd+Shift+.

### 3. جيب مفتاح الذكاء الاصطناعي
- سجل فـ console.anthropic.com وزيد شوية الرصيد (5 دولار كيكفيو لمدة طويلة، حيت الموديل المستعمل رخيص).
- دخل لـ **API Keys** وصاوب مفتاح جديد، وكوبيه.
- رجع لـ GitHub: **Settings > Secrets and variables > Actions > New repository secret**
  - Name: `ANTHROPIC_API_KEY`
  - Secret: المفتاح اللي كوبيتي

### 4. فعل النشر
- فـ GitHub: **Settings > Pages**، ففين كاين Source اختار **GitHub Actions**.
- فنفس الصفحة، فـ **Custom domain** كتب الدومين ديالك (بحال `www.dailytwist.fun`).
- فالموقع اللي شريتي منو الدومين، زيد DNS record:
  - Type: `CNAME` — Name: `www` — Value: `اسمك.github.io`
- رجع لـ GitHub وفعل **Enforce HTTPS** ملي يولي متاح.

### 5. بدل المعلومات ديالك فـ `config.json`
فـ GitHub حل الملف `config.json`، اضغط على القلم ✏️ وبدل:
- `site_url` → الدومين ديالك مثلا `https://www.dailytwist.fun`
- `contact_email` → إيميل ديال التواصل (الأحسن تصاوب إيميل جديد خاص بالموقع)
- `site_name` → إلا بغيتي تبدل السمية

### 6. شعل الوكيل أول مرة
- دخل لـ **Actions**، اختار **Daily AI agent + publish**، واضغط **Run workflow**.
- فـ backfill_days كتب `21` باش يعمر ليك الموقع بمحتوى ديال 3 سيمانات من أول نهار.
- من هنا ولفوق كيخدم بوحدو كل نهار. انت ما خاصك تدير والو.

## أدسنس (من بعد 3 حتى 4 سيمانات)

1. سجل الموقع فـ **Google Search Console** وصيفط ليه `sitemap.xml` باش جوجل يبدا يشوف الصفحات.
2. ملي يكون الموقع فيه محتوى ديال شي 3 سيمانات، سجل فـ **google.com/adsense** وزيد الموقع ديالك.
3. أدسنس غادي يعطيك رقم بحال `ca-pub-1234567890123456`. حطو فـ `config.json` فـ `adsense_client` وحفظ.
   الموقع كيتبنى من جديد بوحدو وكيزيد كود أدسنس و `ads.txt` أوتوماتيكيا.
4. فأدسنس:
   - فعل **Auto ads** (أدسنس كيختار بلايص الإعلانات بوحدو).
   - فـ **Privacy & messaging** فعل رسالة الموافقة **GDPR** (ضرورية للزوار من أوروبا).
5. تسنا الموافقة (من بضعة أيام حتى بضعة سيمانات).

## نصائح باش يبقى الحساب سالم
- عمرك ما تكليكي على الإعلانات ديالك وما تطلب من حد يكليكي.
- ما تشريش الزيارات (traffic) ولا تستعمل برامج الزيارات المزيفة.
- مرة فالسيمانة دخل للموقع وشوف المقالات الجديدة. إلا لقيتي شي غلط، مسح الملف ديالو من `content/articles` فـ GitHub.
- إلا جاك إيميل من شي واحد كيقول كاين غلط، صلحو بسرعة.

## التكلفة
- GitHub والاستضافة: مجانية.
- الدومين: تقريبا 10 دولار فالعام.
- الذكاء الاصطناعي: غالبا بضعة دولارات فالشهر (تقدر تشوف الاستهلاك فـ console.anthropic.com).

## الملفات
| الملف | الدور |
|---|---|
| `agent/run_daily.py` | الوكيل: كيجيب المواضيع الرائجة وكيكتب المحتوى |
| `site_builder/build.py` | كيبني صفحات الموقع |
| `site_builder/assets/` | التصميم، اللغز، الكويز والعدادات |
| `.github/workflows/daily.yml` | الجدول اليومي والنشر الأوتوماتيكي |
| `content/` | المحتوى اللي كيكتبو الوكيل (كيتعمر بوحدو) |
| `config.json` | الإعدادات ديالك |
